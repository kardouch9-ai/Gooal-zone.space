Gooal Zone - الأخبار التلقائية
===============================

تمت إضافة نظام تحديث تلقائي لأخبار كرة القدم باستخدام Netlify Scheduled Functions.

كيف يعمل؟
1. Netlify يشغّل refresh-news كل ساعة.
2. الوظيفة تستدعي Build Hook.
3. Netlify يعيد بناء الموقع.
4. scripts/build-news.mjs يجلب خلاصات RSS ويولّد صفحات أخبار جديدة وnews-data.json وsitemap.xml.
5. الصفحة الرئيسية وصفحة آخر الأخبار تتحدثان تلقائياً.

إعداد ضروري مرة واحدة:
-----------------------
1. في Netlify افتح الموقع.
2. Project configuration > Build & deploy > Build hooks.
3. أنشئ Build Hook جديداً، واختر الفرع الرئيسي (عادة main أو master).
4. انسخ رابط الـ Build Hook.
5. افتح Environment variables وأضف:
   BUILD_HOOK_URL = رابط Build Hook
6. أعد نشر الموقع مرة واحدة.

بعد ذلك تعمل Scheduled Function كل ساعة.
Netlify يستخدم UTC في cron. يمكن تغيير @hourly لاحقاً إذا أردت تكراراً مختلفاً.

مصادر RSS الافتراضية موجودة داخل scripts/build-news.mjs، ويمكن تغييرها بواسطة متغير NEWS_FEEDS.
الصيغة:
اسم المصدر|رابط RSS|التصنيف||اسم مصدر آخر|رابط RSS|التصنيف

مهم:
-----
- النظام يعرض العنوان والملخص ويربط بالمصدر الأصلي؛ لا ينسخ المقال الكامل.
- إذا تعطل مصدر RSS، يتجاهله النظام ويحاول بقية المصادر.
- إذا لم يتوفر أي مصدر أثناء البناء، يحتفظ الموقع بالمحتوى الحالي بدلاً من إفراغه.
- راجع شروط استخدام كل مصدر RSS قبل الاعتماد التجاري عليه.
